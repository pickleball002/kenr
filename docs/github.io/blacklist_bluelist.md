The blacklist file removes players from the overall ranking that should not populate \
through the system.   Like 'Rando' and 'Randa'.  Used for ranking but not for io.

bluelist is for private groups where a player's update is taken but chooses not to appear.

Example

I might participate in games with a private group.  But chose to not appear in ranks with them.  \
(bluelist for each private group)
